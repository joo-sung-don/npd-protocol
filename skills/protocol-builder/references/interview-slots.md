# 인터뷰 슬롯

## 필수 슬롯

| # | 슬롯 | 질문 예시 | 선택지 / 예시 |
|---|---|---|---|
| 1 | 제품군 | 어떤 제품군인가요? | srPET 복합재 / EcoFlamix 난연재 / srPET+EcoFlamix 결합 / 신규 소재 |
| 2 | 적용 산업 | 어느 산업에 적용하나요? | 자동차 / 항공 / 해양(선박) / 건축 / 필터·섬유 / 기타 |
| 3 | 부품·용도 | 구체적인 부품과 기능은? | 도어 트림, 시트백, 기내 사이드월 패널, 선실 칸막이, 단열재 등 |
| 4 | 구조·형태 | 어떤 구조인가요? | 단판(적층 수) / 샌드위치(PET 폼 또는 허니컴 코어) / 부직포 / 코팅·함침 처리 |
| 5 | 목표 특성값 | 꼭 만족해야 할 특성과 목표값은? | 비강도, 굴곡강성, 충격, 난연 등급, 밀도, 두께 등 |
| 6 | 비교 기준 | 무엇을 대체하거나 무엇과 비교하나요? | GFRP, PP 복합재, 할로겐계 난연재, 기존 고객 부품 |
| 7 | 사용 환경 | 사용 온도 범위, 습도, 하중, 화학 노출, UV, 수명은? | 예: -40~85°C, 실내, 10년 |
| 8 | 대상 시장·고객 | 판매 지역과 고객사는? | 국내 / EU / 미국 / 기타. 고객사명, 고객 규격 번호를 알면 함께 |
| 9 | 개발 단계·일정 | 지금 단계와 목표 일정은? | 개념 / 시제품 / 양산 전, 목표 시점 |

## 슬롯을 받은 뒤 확인할 것

- 적용 산업 × 부품 조합으로 화재안전 규격이 정해진다(knowledge/standards). 산업이 둘 이상이면 각각 확인한다.
- 목표 특성값에 단위나 조건이 없으면 되묻는다. 예: "강도 높게"라고 하면 "어떤 강도(인장/굴곡/충격)를, 어느 정도로?"라고 묻는다.
